## The headline pivot from the original PDF

The original plan's main project ("Reliability Maps for Agentic LLM Systems") is solid but generic. **A dozen other MATS applicants will pitch something similar.** This vault keeps the engineering scaffolding (eval harness, multi-model, mitigations) but reframes the project around your actual edge:

> **"Phase Diagrams of Agent Failure"** — treating reliability collapse under context perturbation as a phase transition. Borrow language and analysis tools from statistical mechanics. Find critical points. Plot order parameters. This is something only a physicist would build, and it makes the project memorable.

Two backup framings are in [[02-Main-Project#Creative Angles]] in case the phase-diagram framing doesn't excite you after Day 3.
